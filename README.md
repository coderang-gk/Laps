# COROS Modern Watch Face Vault (120 Combinations)

> **📦 Direct Download**: [Download coros_watchface_vault.zip (31 MB)](https://github.com/coderang-gk/Laps/raw/watchface-vault/coros_watchface_vault.zip)

A complete collection of modern, high-contrast athletic watch faces inspired by Google Pixel Watch & Material You typography, built for all COROS smartwatches.

## Supported Watch Models

- **COROS PACE Pro** (416×416 AMOLED) — Template ID: `416901`
- **COROS PACE 3** (260×260 Memory LCD) — Template ID: `260902`
- **COROS APEX 2 Pro / VERTIX 2** (260×260 Memory LCD) — Template ID: `260902`
- **COROS PACE 2 / APEX 42** (240×240 Memory LCD) — Template ID: `240901`

## Included Watch Face Styles

- **Pixel Bold Bubbly**
- **Pixel Stacked Bold**
- **Pixel Concentric**
- **Laps Radial Track**
- **Expedition Sport**

## Typography Choices

- **Bubbly** (`google_sans_flex_bubbly.ttf`)
- **Tall Serif** (`pixel_tall_serif.ttf`)
- **Clean Sans** (`google_sans_clock_600.ttf`)
- **Stacked Bold** (`google_sans_flex_stacked.ttf`)
- **Thin Rounded** (`pixel_rounded_thin.ttf`)
- **Block Cutout** (`pixel_block_cutout.ttf`)

## Flashing Instructions

1. **Mobile (Instant)**: Open **Laps** on Android ➔ Watch Face Tab ➔ Tap **Sync Watch**.
2. **Desktop (CorosLink)**: Visit [watchfaces.coroslink.com](https://watchfaces.coroslink.com) ➔ Import the `.zip` or `.bin` file ➔ Send to watch.
